# Triage labels

Use these existing category labels and state labels for GitHub issues. Each triaged issue should have exactly one category and one state label.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `bug` | `bug` | Existing behavior is broken |
| `enhancement` | `enhancement` | New or improved behavior is requested |
| `needs-triage` | `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for the reporter |
| `ready-for-agent` | `ready-for-agent` | Specified enough for an agent to work on when asked |
| `ready-for-human` | `ready-for-human` | Needs a human decision or action |
| `wontfix` | `wontfix` | Closed with a recorded reason |

The label mapping is literal: the role and GitHub label names are the same. Triage is initiated on request; no label triggers automatic work or merging.
