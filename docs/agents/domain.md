# Domain docs

This is a single-context repository. Before exploring a domain area, read the root `CONTEXT.md` and relevant ADRs under `docs/adr/` if they exist. They are created only when real terminology or decisions need recording; their absence is not an error.

Use terms defined in `CONTEXT.md` when it exists. Surface a conflict with an existing ADR instead of silently overriding it. The current source and runtime evidence still determine current behavior.
